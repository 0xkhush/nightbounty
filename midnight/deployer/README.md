# NightBounty Midnight PreProd deployer

A deployment-only TypeScript runner for the existing NightBounty Compact artifact at `../contract/managed/nightbounty`. It deploys no other contract.

The runner uses the artifact generated by Compactc `0.31.1` / compact runtime `0.16.0`, with the compatible Midnight.js `4.1.1` provider packages. It deploys only to Midnight **PreProd**:

- Indexer: `https://indexer.preprod.midnight.network/api/v4/graphql`
- Node: `https://rpc.preprod.midnight.network`
- Faucet: `https://midnight-tmnight-preprod.nethermind.dev/`
- Local proof server: `http://127.0.0.1:6300`

## Safe run

1. Use Node `>=24.11.1` and Docker Desktop. Run commands from this directory:

   ```sh
   cd /Users/khush/Documents/hacathons/hackathon2/midnight/deployer
   npm ci
   npm run proof-server:up
   npm run deploy
   ```

2. Select either a fresh wallet or recovery from an existing 32-byte hexadecimal seed. Recovery seeds and the private-state password are entered with terminal echo disabled.
3. For a fresh wallet, record the one-time recovery seed shown on **stderr** before confirming it. Do not redirect stderr, use `tee`, paste it into shell history, or commit it anywhere.
4. The runner prints its public PreProd faucet address to the terminal, requests faucet funds when needed, waits for wallet synchronization, registers faucet UTXOs to generate tDUST, waits for tDUST, then calls Midnight.js `deployContract` using the generated NightBounty bindings. If the faucet request is unavailable, use the printed address at <https://midnight-tmnight-preprod.nethermind.dev/> and rerun with the same recovery seed.

On success, **stdout contains exactly one JSON object of public deployment evidence**: the network, contract address, deployment transaction hash, block height, and artifact versions. Prompts and non-secret status messages use stderr. No seed, storage password, private witness key, balances, or private state is emitted in the evidence JSON.

Example shape:

```json
{
  "network": "preprod",
  "contractAddress": "…",
  "deployTxHash": "…",
  "blockHeight": "…",
  "compactCompiler": "0.31.1",
  "compactRuntime": "0.16.0"
}
```

Copy the successful evidence into the ignored `midnight/deployment.json` file using the Streamlit field names:

```json
{
  "network": "PreProd",
  "contract_address": "<contractAddress>",
  "deployment_transaction": "<deployTxHash>"
}
```

For Streamlit Community Cloud, add those same values as root-level `NIGHTBOUNTY_CONTRACT_ADDRESS` and `NIGHTBOUNTY_DEPLOYMENT_TX` secrets instead.

Stop the local proof server when finished:

```sh
npm run proof-server:down
```

## Private state and recovery warnings

- `localSecretKey` is a new cryptographically random 32-byte value in `NightBountyPrivateState`. The generated contract witness reads that value only from local private state.
- The local Level stores are created at `.private-state/` and protected by the password prompted at runtime. They are ignored by Git. The private state is needed to prove ownership for future owner-only NightBounty circuits; preserve it securely along with its password and the wallet recovery seed.
- This package deliberately has no seed, password, API token, private key, or contract-specific secret in source, configuration, or compose files.
- PreProd tokens and deployments are test assets. Faucet availability and synchronization time are external dependencies; the funding/tDUST wait has a 10-minute timeout. A timeout or faucet error emits no deployment evidence JSON and submits no contract deployment transaction.
- This runner deploys a new contract every time it completes successfully. It does not join, administer, submit reports to, or deploy any other contract.

## Validation

```sh
npm run typecheck
npm run build
```

`npm run deploy` runs the build before starting the interactive deployment. A real deployment additionally requires network access, a healthy local proof server at port `6300`, and a funded PreProd faucet response.
